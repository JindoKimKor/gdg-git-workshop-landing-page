# Landing Page Requirements

## Overview

Build a responsive landing page for GDG Conestoga with three main sections: a navigation bar, a hero section, and a footer.

## Pages

- Single page (`index.html`)

## Sections

### 1. Navbar

- Logo or site name on the left
- Navigation links on the right: Home, About, Contact
- Hamburger menu for mobile viewport
- Background color changes on scroll (transparent → solid)
- Smooth CSS transition for scroll effect
- Sticky positioning (stays at top when scrolling)

### 2. Hero Section

- Large heading with a welcome message
- Short description paragraph below the heading
- Call-to-action button (e.g., "Get Started" or "Learn More")
- Background gradient or background image
- Centered content layout
- Responsive: text and button scale properly on mobile

### 3. Footer

- 3-column layout:
  - **About**: Brief description of the site/project
  - **Quick Links**: Home, About, Contact
  - **Contact**: Email, phone, or placeholder info
- Social media icon placeholders (GitHub, LinkedIn, Twitter)
- Copyright text at the bottom (e.g., "© 2026 GDG Conestoga")
- Responsive: columns stack vertically on mobile
- Dark background with light text

## Technical Constraints

- Pure HTML, CSS, and vanilla JavaScript only
- No frameworks or libraries
- Mobile-first responsive design
- Must work by opening `index.html` directly in a browser (no build step)
